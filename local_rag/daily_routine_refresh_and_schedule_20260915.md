# Daily routine Spain refresh reporting and schedule

- User request and scope: report Spain `refresh_mv.py` errors (up to five in the preceding 48 hours), report failure if it did not execute, and run the routine every day at 08:00.
- Implementation: `daily_rutione_check` calls the existing read-only `inspect_saved_sync_process_status` diagnostic only for `es_db2_orclsp_sys`. It emits at most five `DAILY_TRANSFER` records with state `ERROR`; when no records exist in the trailing two days, it emits a 48-hour execution failure. Generic job and refresh statuses remain excluded. Error text is whitespace-normalized and bounded to 300 characters for the three-message Slack limit.
- Scheduling: the repository MCP tool `configure_daily_routine_schedule` creates and verifies the local Task Scheduler task `\\OracleMCP\\DailyRoutine`, running daily at 08:00 through `myoracle_mcp/daily_routine_runner.py` and the configured Slack DM.
